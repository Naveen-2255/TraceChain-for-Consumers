# TraceChain Mobile (React Native / Expo)

This is the complete React Native Expo version of TraceChain with the concentric curved navigation bar and custom color palette.

## How to Run on Your Physical Phone:

1. **Install dependencies**:
   ```bash
   cd react-native
   npm install
   ```

2. **Start the development server**:
   ```bash
   npx expo start
   ```

3. **Open on your device**:
   - Install **Expo Go** from Google Play Store (Android) or App Store (iPhone).
   - Scan the QR code displayed in your terminal.
